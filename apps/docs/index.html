How to use Release Lab Blog

For readers

  1. Open the blog. The newest post is at the top.
  2. Select a post title to read the full post and its comments.
  3. Type in the comment box and select Post comment. Empty comments are rejected.

For staff

  1. Open the staff app in a browser or start the desktop app.
  2. Select New post, enter a title (up to 200 characters) and a body, then select Create post.
  3. Select a post in the list to edit it. Select Save changes to save.
  4. Comments for the post show below the edit form. Staff can read comments but not edit them.

Mobile

The mobile app lists posts, shows a post with its comments, and lets you add a comment.

Versions

Each release has one version, such as v1.0.0, that covers every app. Mobile app stores also show a build number. The build number is not the release version.
